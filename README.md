# Driveway Detailing Co. website

Static one-page site for Driveway Detailing Co., a mobile car detailing business serving Plano, Richardson, Allen, Frisco, McKinney and surrounding areas.

Files: `index.html`, `styles.css`, `script.js`, `favicon.svg`. No build step — open `index.html` in a browser.

## Settings (top of `script.js`)
- `QUOTE_EMAIL` — where booking requests from the form go (currently ahopdrivewaydetailing@gmail.com)
- `BOOKING_URL` — paste your Calendly booking link and every "Book" button opens it
- `PHONE` — add a business phone number to show it in the contact section

## Hosting
Works on any static host (GitHub Pages, Netlify, Cloudflare Pages). The request form opens the visitor's email app; for direct submissions, point it at Formspree.
