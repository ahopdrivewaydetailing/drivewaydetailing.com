# Driveway Detailing website

Static one-page site: `index.html`, `styles.css`, `script.js`, `favicon.svg`. No build step — open `index.html` in a browser.

## Things to customize
- Phone number `(555) 555-5555` / `tel:+15555555555` in `index.html`
- Email `info@drivewaydetailing.com` in `index.html` and `QUOTE_EMAIL` in `script.js`
- Hours, service area, package prices, stats, and FAQ answers in `index.html`
- Sample reviews and placeholder before/after gallery — replace with real ones

## Hosting
Works on any static host (GitHub Pages, Netlify, Cloudflare Pages). The quote form opens the visitor's email app; for direct form submissions, point it at Formspree or Netlify Forms.
